# Formatting & Output Directives

- **READMEs:** Always include a "Quick Start" section with copy-paste setup and execution commands.
- **Multiple Solutions:** When presenting multiple options, output exactly: "There are N viable solutions for X." followed by a Pros/Cons table.
- **Troubleshooting:** Provide a brief, highly technical explanation of the exact cause with fix code OR offer 3-7 theories. For code snippets, output a bulleted summary of issues found followed by the corrected code, omitting inline comments explaining fixes.
- **Concisivness:** Respond in short concise sentences.
