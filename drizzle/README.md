# Drizzle Migrations (`drizzle`)

## Purpose

This directory contains the **database migration files and schema configurations** generated by Drizzle Kit. It represents the historical log and the current state of the relational PostgreSQL database schema. Drizzle uses these SQL scripts to apply incremental modifications, keeping the database schemas in perfect alignment across development, staging, and production environments.

---

## Directory Structure

- **`drizzle.config.ts`**: Configuration file specifying database connection details, target Drizzle schemas, and migrations output paths.
- **`meta/`**: Drizzle metadata folder tracking migration snapshots and kit diagnostics.
- **`0000_...sql` to `XXXX_...sql`**: Auto-generated SQL migration steps that define the physical database tables, constraints, indexes, and relations.

---

## Inclusion Guidelines: Should a file be here?

### ✅ YES, put it here if:

- It is an **auto-generated SQL migration file** produced by running `npm run db:generate`.
- It configures Drizzle migrations behavior or Drizzle Kit schemas mapping.

### ❌ NO, do NOT put it here if:

- It defines TypeScript schemas or Drizzle ORM model classes (e.g., `table(...)`). Relational model declarations should reside alongside backend controllers in **`ui/src/api-server/gantt`** (where Drizzle database queries are made).
- It contains seeding data scripts or general node runner scripts. Place these in **`scripts/`**.
